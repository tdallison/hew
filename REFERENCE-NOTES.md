# Reference and implementation notes

## Observed reference behavior

- The supplied `SketchUp7Help.pdf` describes the Select tool and modifiers on printed pages 130-136, Line on 146-149, Rectangle on 163-167, and Push/Pull on 205-208. It describes inference cues on pages 121-122 and 580-584. The PDF is behavioral documentation; it does not specify the inference algorithm or thresholds.
- The SketchUp 8 `Plugins/Examples/linetool.rb` example uses `Sketchup::InputPoint`, shows reference-point picking, Shift locking, a live length, Escape, and click/drag gestures. It creates construction lines, not ordinary pencil edges.
- A prior REA/Ghidra overview of the supplied x86 executable with SHA-256 `81484cc68070239d3852cb2fd4e1f7722c3cd96da9bc11973ca365fd5dd178d5` reported 48,109 recognized procedures and 13,280 defined strings. The temporary Ghidra project was not retained; those counts do not establish complete recovery.
- A read-only byte scan located names including `CInputPointFinder`, `CInputPointManager`, and input-point classes for vertex, midpoint, edge, face, axis, intersection and constraints, along with Rectangle and Push/Pull class names. These names suggest areas for investigation; they do not establish ranking, tolerances, state transitions, or topology. A subsequent targeted Ghidra search timed out during import without producing search evidence. The executable's PDB was unavailable.
- A later Ghidra import with a 30-minute startup allowance completed successfully and traced focused native routines. See [SKETCHUP8-INFERENCE-INVESTIGATION.md](SKETCHUP8-INFERENCE-INVESTIGATION.md) and its exported Evidence bundle for the static findings and remaining unknowns. No native runtime trace was recorded.
- The 2026-11-05 follow-up saved 69 evidence records and a query snapshot. Static findings include normalized ray construction, a conditional 3D distance comparison, Shift-related resets, signed Push/Pull distances, a pointer-coordinate movement gate, Ctrl mode toggling, and limiting/rounding paths. Native coordinate units and complete controller semantics remain unresolved.
- Direct UI and Ruby API observations in the supplied SketchUp 8 established simple cap merging, retained-face mode, an exact inset through-cut, and a bounded endpoint acquisition measurement. See [SKETCHUP8-RUNTIME-COMPARISON.md](SKETCHUP8-RUNTIME-COMPARISON.md) for fixtures, outputs, and distinctions between API results, native-code evidence, and independent implementation choices.

## Design choices and open questions

Candidate ordering and most screen-distance thresholds remain independent choices. A 6-pixel endpoint radius approximates a controlled native API sample; edge and axis apertures still require measurement. The viewport uses an orthographic camera, a planar edge graph, and OpenGL rendering. The geometry tests demonstrate supported cases, not equivalence to SketchUp's geometry engine. Full inference locking semantics, inference from hovered geometry, complete cue rendering, robust solid operations, native tolerance unit conversion, and exact post-operation editing remain incomplete.

The Boolean implementation is an independent polygon BSP experiment, not a recovered SketchUp algorithm. It checks and reconstructs a closed model transactionally; unsupported or ambiguous configurations fail without changing the model. A guarded convex vertical-prism reconstruction now handles the previously rejected rotated square-prism intersection fixture, including its expected volume and model reconstruction. This does not establish general rotated-solid support. The existing inference query snapshot stores replayable query evidence, not a full reusable Ghidra database.

Ghidra startup and individual function decompilations are each configured for 30 minutes; Codex's separate `mcp_servers.rea.tool_timeout_sec` is also set to 30 minutes for future sessions. Reconnect or restart Codex to load the persistent configuration. These are separate limits, not a single wall-clock deadline for a series of operations. A standalone REA CLI run can avoid the current session's previous MCP request deadline. See [the validated configuration helper](reference/configure-rea-timeouts.py).

The SketchUp 8 toolbar screenshot supplied in this conversation is a visual reference. The buttons in this project are original drawings, not extracted SketchUp assets.
